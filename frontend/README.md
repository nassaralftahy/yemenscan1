# YemenScan - Frontend Application (React + TypeScript + Tailwind CSS)

واجهة المستخدم المتقدمة لمنصة **YemenScan** لإدارة سطح الهجوم السيبراني وتتبع الثغرات الأمنية، متصلة مباشرة مع خادم FastAPI.

## المميزات التقنية:
1. **لوحة تحكم تفاعلية (Dashboard)**:
   - إدخال وفحص النطاقات المستهدفة.
   - شريط تقدم لحظي (Real-time Progress) ومراحل الفحص الثلاث عبر Polling دوري.
   - بطاقات إحصائية للأصول والثغرات وتوزيع درجات الخطورة.
2. **تبويبات استعراض النتائج**:
   - **الأصول والمسارات المكتشفة**: جدول مرن يدعم البحث والفرز وعرض خوادم الويب وواجهات APIs ومكتبات التقنية.
   - **سجل الثغرات الأمنية**: بطاقات تفاعلية مصنفة حسب الخطورة (Critical, High, Medium, Low) مع عرض معايير CVE, CWE, CVSS, OWASP ودليل الاستغلال وخطوات المعالجة.
   - **استشارات الذكاء الاصطناعي (AI Advisory)**:
     - التقرير التنفيذي للإدارة العليا (CISO Executive Report).
     - التقرير التقني المفصل للمطورين (Technical Remediation Report).
     - دعم التخزين المؤقت في قاعدة البيانات (DB Caching).
     - عزل الأكواد البرمجية ومحاذاتها لليسار (LTR) مع إمكانية النسخ الفوري.
     - تصدير مباشر إلى Markdown و HTML و JSON وطباعة PDF نظيفة خالية من انقسام الأكواد بين الصفحات.

## متطلبات التشغيل والتثبيت:

### 1. تشغيل خادم الواجهة الخلفية (Backend - FastAPI):
```bash
# من المجلد الرئيسي للمشروع:
python -m uvicorn main:app --reload --port 8000
```

### 2. تثبيت حزم الواجهة الأمامية (Frontend):
```bash
cd frontend
npm install
```

### 3. تشغيل الواجهة في وضع التطوير (Development):
```bash
npm run dev
```
ستعمل الواجهة على: `http://localhost:3000` وستقوم بتحويل طلبات الـ API تلقائياً إلى `http://localhost:8000`.

### 4. بناء نسخة الإنتاج (Production Build):
```bash
npm run build
```
